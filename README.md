# deluispablo.com

Portfolio de Pablo de Luis.

- `/healthtracker/`: [Health Tracker](https://github.com/deluispablo/health-tracker), app para Pixel Watch, dashboard y análisis de tus propios datos de salud.

Sitio estático en `public/`, servido por un Worker de Cloudflare con static assets (`wrangler.jsonc`). Mientras no haya portada, la raíz redirige a `/healthtracker/`.
